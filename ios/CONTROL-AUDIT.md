## 设置

当前设置包含低电量优先、裁切重算效果尺度（默认关）、DI 蓝色补偿（默认关）、释放缓存和引擎／工作空间说明。预览已改为按屏幕像素自动选择 Fit、合并交互更新并渐进补充视口细节，不再提供固定预览分辨率选择器；完整分辨率导出独立于预览。偏好和导出配方独立保存。导入原文件与编辑记录保存在应用内图库，重启后仍可继续编辑；设置显示照片数量，与内存分组分开。旧预览尺寸和设备测量记录见历史快照，不是当前菜单契约。

桌面语言/界面比例、快速材料LUT预览、详细日志/GPU逐节点计时、磁盘缓存策略、内存配额手动越限、宿主机器诊断没有做成手机里的空开关。手机使用自动内存保护，不沿用桌面无限制配额。

## 导出

已接JPEG、PNG、16位TIFF和Cineon DI。普通成片可选Display P3（默认）、sRGB、Adobe RGB，TIFF另可选ProPhoto；质量默认95%。普通成片复用当前桌面GPU输出变换，避免额外的色调压缩。

范围支持当前/全部/保留/当前筛选结果；尺寸支持6/12/24/36/48MP、长边、完整分辨率（不放大，均受可用内存保护）；文件名通过原名/胶片/相纸/日期/序号勾选组合，不展示占位符语法；可保留拍摄元数据、单独去定位、选择文件夹、同名追加/覆盖/跳过。支持保存命名导出配方。TIFF可附预览页。DI为未标ICC的16位Cineon TIFF+两个桌面视图LUT，不能作为普通成片写入照片图库。

仍未移植：自装ICC、软打样、桌面对照导出网格、半格组片相关输出。目录权限按本次会话取得。批量顺序处理，避免同时保留多张高分辨率渲染。

## 本地图库与编辑项复制

本地清单原子持久化照片身份、原文件相对路径、配方、构图、评分与旗标；
损坏清单保留且不得被空会话覆盖。删除先提交缩减后的清单，再移除应用文件。
预览JPEG属于缓存；GPU资源与撤销历史不跨进程恢复。

图库提供筛选、多选、滑动范围选择、批量编辑及固定目标ID批量导出。单张
编辑隐藏照片条，批次只显示所选照片。复制可选择参数组；裁切仅复制比例，
按目标横竖方向适配并保留目标构图、校直、转向与翻转。导出格式的可用性、
Photos权限及当前内存门限仍独立检查。

## Duo 成片缩略图 · 2026-11-04

根因为目录枚举返回的 URL 与写入 URL 对同一文件名比较不等，旧的
`old != url` 清理条件会误删刚生成的 JPEG。改为同目录按文件名排除当前
文件，并在后台写入完成后通知图库刷新。

Duo 实机诊断确认 URL 比较差异存在，修复后缓存文件留存；用户确认图库
显示编辑后效果。排查用 JSON 诊断、退出补存与去重状态、替代缩图路径均已
移除，缩图恢复原有 Core Image 实现。未将上述根因误归于 RAW 解码或 GPU
资源压力。诊断和导出文件未纳入仓库。

## PR #4 重复选择工艺回归 · 2026-11-04

自动审查指出原生分段控件不会在再次点击当前选中项时发出切换事件，

开始与结束都指向当前选中项时执行工艺动作；其他选择继续使用原生切换事件。
