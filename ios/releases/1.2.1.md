# Silverphase iOS 1.2.1 (7) release preparation

Source candidate, 2026-11-09. This document records preparation, not an App Store
or TestFlight upload, review submission or public release.

## Changes

- Default fluent approximate film viewfinder with cached HDR-shaped independent
  colour samples, metering and diffusion. System and experimental native modes
  remain available; existing native selections migrate once, explicit off stays off.
- Processed shutter freeze, continuous digital-zoom preview, and lens/portrait
  transitions that wait for a processed frame from the new input configuration.
- Camera-only device-relative layout and rotating controls across orientations;
  lock-screen capture inherits film without a picker and exposes meter/diffusion.
- Optional foreground capture location tagging, enabled by default and subject
  to permission; metadata follows the existing export location policy.
- Standard photo-deletion alert and iOS 18 parameter label colour compatibility.
- Additive native ABI for stream input replacement, ephemeral viewfinder output
  and independent colour samples. Material profiles and still-render policy unchanged.

## Known limits and submission gates

- Video is already processed by the camera ISP. Approximate preview is for
  composition; experimental native preview also cannot reproduce RAW input.
- Lock-screen activation stalls remain an unresolved prior limitation. Orientation,
  folded/unfolded Duo handoff, physical lens/portrait transitions and secure capture
  require signed-device acceptance on the final candidate.
- A TestFlight iPad8,11 GPU InnocentVictim export error lacks the original,
  recipe and export journal. It is not reproduced or claimed fixed. No targeted
  retry or resolution/recipe degradation is introduced.
- Text feedback was reproduced on iPadOS 18.6; exact 18.7.8 hardware is unverified.
- Validate signed Release cold start, camera/Photos/location permission states,
  persistence, full-resolution Files/Photos export and memory behavior on iPhone/iPad.
- Inspect archive versions, public resources, privacy manifest, licensing and
  increased-memory entitlement; retain corresponding source and dSYMs.
- Verify store description/privacy answers, signing/provisioning, legal/regional
  prerequisites and unresolved items in [APP-STORE.md](../APP-STORE.md).
- Upload, review submission, merge/tag and publication are separate actions.

Private photographs, TestFlight attachments, source evidence and device diagnostics
remain outside Git. Workspace cleanup preserves those inputs and the retained
