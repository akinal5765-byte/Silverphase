# Digital Intermediate view tables

Imported unchanged from Hanze Qiu’s SpektraLab 1.2.2, commit
`4cab8b6a91fea88a1f23f5f00f03e35dd9ab38f0` (RFC-028–030).
The original filenames and titles retain their upstream attribution.

The tables are generated by `Canvas/CineonLUT.swift`: Kodak Cineon decode,
luminance shoulder, constant-hue gamut mapping and output encoding. The
ProPhoto table is used by the canvas; both tables accompany Cineon masters.
They are viewing transforms and are never baked into the master file.
