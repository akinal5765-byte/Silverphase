# Silverphase macOS 1.4.0（构建 7）

**中文 · [English](#english)**

适用于 Apple Silicon、macOS 15 或更新版本。
这是桌面版更新，不代表 iPhone 或 iPad 已发布相同变更。
[公开下载与安装说明](../../../docs/BINARY-RELEASES.md) · [从 1.3.1 升级](../../../docs/MACOS-IDENTITY-UPGRADE.md)

## 本版更新

- **胶片与相纸封面重绘。** 63 个内置材料条目使用 57 张独立的 16:9 封面，同一材料的部分变体共用设计。封面更换不改变胶片或相纸配方。[封面展廊](../../../README.md#胶片封面) · [素材来源与许可](../../../license/ARTWORK.md)
- **导出更少压低原本能显示的颜色。** 参考 Hanze Qiu 的 [SpektraLab 输出色域策略](https://github.com/JamesQiu2005/SpektraLab/commit/d661b3b957adfd0fa90259d7c3b67cfe0d996165)，主要在接近目标色域边界时才压缩色度。鲜艳颜色超出 sRGB 时仍会收敛，来回切换普通画布与 sRGB 软打样时尤其容易看出。目标是保住可保留的颜色，不是让两种视图完全相同。用 Display P3 交付时，先确认对方的应用和屏幕支持；需要 sRGB 时，以 sRGB 软打样为准。
- **自定义片边文字。** 可为单照片或半格双联画替换片边上的胶片名称。清空后恢复默认；画框、齿孔与帧号不变。
- **Hasselblad 3FR 裁切。** 新导入时尝试采用兼容文件的机内裁切作为非破坏性默认构图。不覆盖已有编辑；实拍裁切 3FR 尚需验收。
- **独立的 Mac 应用身份。** 标识符改为 `com.silverphase.editor`，日志、缓存和编辑数据与 SpektraLab 分开。App 不会自动迁移旧偏好、编辑记录或导出配方，升级前请先备份并按[迁移指南](../../../docs/MACOS-IDENTITY-UPGRADE.md)选择性复制。
- **诊断可记录材料指纹。** macOS 手动保存的诊断包可报告当前材料的 SHA-256。它可用来排查材料差异，不是旧编辑的版本号，也不能单凭指纹判断色差原因。

## 验证与限制

Apple Silicon Release DMG 已构建并验证镜像完整性、签名、架构和应用标识符；安装包用 ad-hoc 签名，未公证。输出转换做了实图与高饱和渐变测试。在一张不随项目分发的本地 RAW 上，固定同一渲染只切换算法，新版 sRGB 和 Display P3 都更接近未压缩参考。关闭随机颗粒和眩光后，两种色域的 16 位 TIFF 读回与对应软打样逐像素一致。测试不承诺超色域颜色能无损转换，也不等于所有 RAW、文件格式与显示器均已验收。

涉及真实图库迁移、与 SpektraLab 并行使用或 Lightroom Classic 的用户，请保留旧版并按指南逐项验证；本说明不声称覆盖所有环境。详见[桌面升级检查清单](../../../docs/MACOS-IDENTITY-UPGRADE.md#desktop-release-gate-for-maintainers)。

## English

Apple Silicon, macOS 15 or later. This update is for macOS; it does not indicate the same changes are available on iPhone or iPad. [Download and installation](../../../docs/BINARY-RELEASES.md) · [Upgrade from 1.3.1](../../../docs/MACOS-IDENTITY-UPGRADE.md).

### Changes
- **Redesigned film and paper covers.** 57 distinct 16:9 designs cover 63 built-in material entries; some variants share a design. The covers do not change the recipes. [Cover gallery](../../../README.en.md#film-cover-gallery) · [Artwork provenance](../../../license/ARTWORK.md).
- **Less compression for reproducible colours.** Based on [SpektraLab's output gamut policy](https://github.com/JamesQiu2005/SpektraLab/commit/d661b3b957adfd0fa90259d7c3b67cfe0d996165), chroma compression mainly acts near the destination gamut boundary. Out-of-gamut colours still contract in sRGB, which can be noticeable when toggling sRGB soft proofing. Use the proof for sRGB delivery and confirm Display P3 support across the receiving app and display before delivering P3.
- **Custom film-edge text.** Replace the stock name on a single photo or a half-frame pair. Clear the text to restore the default. Borders, perforations, and frame numbers are unchanged.
- **Hasselblad 3FR crops.** The importer can adopt supported in-camera crops as non-destructive defaults for new files without replacing existing edits. Real cropped 3FR files still need validation.
- **Separate app identity.** The Mac bundle identifier is now `com.silverphase.editor`. Caches, logs and edits are separate from SpektraLab. Back up and selectively migrate old settings, edits and presets using the [upgrade guide](../../../docs/MACOS-IDENTITY-UPGRADE.md); they are not imported automatically.
- **Material fingerprint in diagnostics.** A manually saved diagnostic can include the SHA-256 fingerprint of the current materials. This is not an edit-version marker or a diagnosis by itself.

### Verification and limits
The Apple Silicon Release DMG passed image, signature, architecture and bundle-identifier verification. It is ad-hoc signed, not notarized. Tests used real photos and saturated gradients. On one private RAW, both sRGB and Display P3 produced results closer to the uncompressed reference with all other settings held fixed. With random grain and glare disabled, 16-bit TIFF readback matched the corresponding proofs pixel for pixel. These checks do not prove lossless conversion of out-of-gamut colours or complete coverage of cameras, formats and displays.

Keep the old app and follow the [desktop upgrade checklist](../../../docs/MACOS-IDENTITY-UPGRADE.md#desktop-release-gate-for-maintainers) when migrating a real library, running both apps, or using Lightroom Classic. [macOS 1.3.1](1.3.1.md).
