# Silverphase macOS 1.3.0（构建 5）

2026-11-18 源码发版准备。macOS 与 iOS 独立编号，iOS 源码仍为 1.2.5（构建 8）。可安装版本以 [GitHub Releases](https://github.com/akinal5765-byte/Silverphase/releases) 和 TestFlight 为准。

## macOS 编辑与导出

- **入片调整。** 在胶片曝光前调节局部亮部和暗部、入片曝光、对比度、低端提升、高端增益、中间调细节、色彩增强和饱和度。旧照片仍可读取原来的高光、阴影、白色色阶和黑色色阶。
- **匹配相机预览亮度。** 受支持的 RAW 可用相机预览拟合起始曝光，高光保护会限制提亮。滑杆标出起始值，后续微调由每张照片保存。复制相机设置会传递匹配开关，目标照片各自计算基准。关闭再开启可重新匹配。
- **模拟尺寸。** 位于「胶片 → 画幅 ⋯」菜单。重裁切后需要输出大图时，可指定裁切后长边，让颗粒和光晕在该尺寸上生成。使用原始尺寸适合日常编辑。应用在入片前重采样，导出配方的尺寸控制仍用于成片缩小。
- **编辑手感与交付。** 调整刻度尺的触控反馈，导出的 JPEG、TIFF 和 PNG 写入照片星级（`xmp:Rating`）。

## 材料与共享引擎

- 「实验」增加 29 款 Fotufilm 胶片配置，由 Noah Haasis 的 Negs 转换，采用独立材料 ID。保留原有近似标记、来源与 CC BY-SA 4.0 授权。公开构建包含这些配置，私有材料通过独立的本地目录管理。
- 共享引擎统一了 DIR 曲线准备与运行阶段的饱和响应。Hanatos 光谱窗口以模型实际的中性光谱归一化，Cineon DI 的中性探针使用相同权重。颗粒柔化按当前渲染像素对应的胶片尺度换算。
- 更新 238 组彩色负片与印相材料的中性滤色配对。校准在 TH-KG3 下通过灰阶和独立半档样点筛选。已保存的照片重新渲染时，使用这些配对的成片可能出现变化。
- 原始实测数组与采用的数据范围见 [材料来源及许可](../../../license/DATA-SOURCES.md) 和 [可追溯记录](../../../engine/resources_product/UPSTREAM.json)。

## 验证范围

- Apple Silicon Release 构建通过。应用包的版本与构建号为 1.3.0（5），包含 63 个公开配置及随附许可。以 `SILVERPHASE_LOCAL_MATERIALS=0` 构建，签名与资源检查通过。
- macOS 全量 XCTest 共 588 项，540 项通过、0 项失败、48 项跳过。跳过项来自缺失的历史照片与未启用的实拍或性能专项。
- 用最终应用包的引擎资源运行 Metal 冒烟测试和 5219 回归，均通过。工程生成、开源资料审计与新增文档链接检查通过。

新增 [Kodak 5219 参考检查](../VALIDATION.md#5219-底片与光谱色样)，包含 14 个原厂曝光点、三个高密度蓝通道颗粒测量点和 24 个实测反射光谱色样。验证记录入片曝光、底片密度、相纸密度和输出 RGB。使用一次曝光对齐后，红、绿、蓝通道平均绝对密度误差为 0.034、0.012、0.008 D。相对直接光谱积分，色样的 RGB 重建误差平均为 0.102 EV，最大为 0.533 EV。三个高密度蓝通道颗粒测量值约低于原厂代表性曲线三分之一。

这些结果验证曲线形状、光谱近似和软件回归。实物胶片的绝对感光速度和端到端成片颜色仍需独立实验。
