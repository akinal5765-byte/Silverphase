# macOS 1.2.0（构建 4）

源码版本准备记录；不表示已上传安装包或发布 GitHub Release。iOS 独立版本不变。

## 新增

- Lightroom Classic 单张 JPEG／TIFF 外部编辑入口，复用 Silverphase.app。
- 专用编辑界面隐藏照片导航和导出，右上角「保存」（⌘S）全尺寸写回
  Lightroom 传入副本，成功后关闭编辑窗口。
- 保留首次输入与编辑配方，避免重复显影；安全写回失败时保留窗口。

配置截图、使用步骤、重复编辑规则与输入边界见
[Lightroom Classic 指南](../../../docs/LIGHTROOM-CLASSIC.md)。

## 效果与范围

沿用现有胶片／印相渲染。没有增加针对 Lightroom 的自动曝光补偿、逆曲线
或默认柔和印相设置。LR 调整已烘焙，同参数不保证与直接 RAW 结果一致。
推荐 SDR、16 位 ProPhoto RGB TIFF。HDR、PSD 和批量往返暂不支持。
