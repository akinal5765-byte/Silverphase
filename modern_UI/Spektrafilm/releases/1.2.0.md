## English

Source-preparation record; it does not indicate that a package was uploaded or a GitHub Release published. The separate iOS version is unchanged.

### Changes
Lightroom Classic can send a single JPEG or TIFF copy to Silverphase.app. The dedicated editor hides photo navigation and export. **Save** (⌘S) writes full resolution to the registered Lightroom copy and closes on success; failures keep the window open. The first input and recipe are retained so repeated editing does not re-develop a finished output. Save waits for committed parameters and the completed render. Finder opens targeting another photo are rejected while external editing is active. [Illustrated Lightroom guide](../../../docs/LIGHTROOM-CLASSIC.md).

### Rendering and limits
This uses the existing film and print pipeline. No Lightroom-specific exposure compensation, inverse tone curve, or soft-print default was added. Lightroom tone is baked into the input and the same recipe need not match a RAW result. Use SDR 16-bit ProPhoto RGB TIFF when possible. HDR, PSD, and batch round trips were not supported.

### Verification
Before PR: 565 desktop tests, 48 skipped, zero failures; fixture-related gaps remain. The maintainer confirmed one local round trip. Launch-state permutations, failure recovery, and preview/save parity were not fully accepted. After the version bump, Debug build and 1.2.0/4 bundle verification passed, as did four focused Lightroom tests, project generation, resource checks, and local document links.
