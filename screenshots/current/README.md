## 100% 颗粒细节

Acros II，135 画幅，颗粒强度、尺度和柔化均为 1×，应用缩放为 100%。
请打开原图以 100% 查看；页面缩图和 JPEG 压缩会影响细小纹理的观感。
原始照片自身的噪声与纹理也保留在画面中。

![Acros II 在 100% 下的颗粒](silverphase-grain-100pct-2026-10-31.jpg)

## 100% 光晕开关

便利店夜景，Vision3 500T，应用缩放为 100%。开启图使用“强”光晕预设、
4× 强度，乳剂散射为 0×，颗粒关闭；关闭图仅关闭光晕，曝光、视角及其他
设置保持一致。这组图展示增强光晕的视觉效果，采用的不是默认强度。
