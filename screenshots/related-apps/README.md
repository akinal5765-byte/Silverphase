# Related application artwork

`layerlight-icon.png` is a 1024 × 1024 native rendering of Layerlight's production
`AppIcon.icon`, supplied from the app owner's local project. It was exported
with Apple Icon Composer's `ictool` using iOS Default, design generation 27,
and scale 1. The source icon was not modified; no app source was copied.
Source-relative paths, source hashes, export settings and the final PNG SHA-256
are recorded in `layerlight-source.json`.

The app owner authorized its use in Silverphase's README to identify and promote
Layerlight. Layerlight is a separate proprietary application available on the
[App Store](https://apps.apple.com/cn/app/layerlight-hdr-photo-editor/id6756343255).
Its name and icon remain subject to their existing rights; they are excluded
from Silverphase's GPL code and CC BY-SA artwork licences.
